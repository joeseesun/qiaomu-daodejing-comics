# 《道德经漫画读本》图文生产方法

目标不是给每句配一张漂亮插画，而是让读者像看漫画一样读懂一句话：先看到一个具体场景，再读原文，再明白这句话为什么成立。

## 核心原则

1. 先分镜，后生图。
   每章先写完整分镜 JSON，不合格不生成图片。

2. 先整章故事，后单句画面。
   每一章必须有连续场景、固定角色或稳定视角。单句画面要服务本章故事推进，不能只是孤立意象。

3. 每句必须可视化为动作。
   禁止只写“表达玄妙”“体现智慧”“展现自然规律”。提示词里必须有可被画出来的人物、动作、物件、空间关系或结果。

4. 图文关系必须能被复述。
   看图后应该能说出：“这张图对应原句里的哪个词、哪层意思、哪个转折。”

5. 风格统一，画面不同。
   统一角色、线条、纸张、色彩和光感；每一格必须更换主体、场景、镜头、前景物和动作。

6. 白话解释连接图和原文。
   白话不是逐字翻译，也不是鸡汤收获。它要解释画面里的动作为什么能帮助理解原文。

## 分镜 JSON 标准

每个 panel 至少包含：

```json
{
  "id": "c01-s01",
  "sentence": "道可道，非常道。",
  "beat": "这一格在本章故事里的推进作用",
  "plain": "给读者看的白话解释",
  "visualAnchor": "这句必须被看见的视觉锚点",
  "primarySubject": "画面主体",
  "setting": "具体地点和时间",
  "action": "人物或事物正在发生什么",
  "foregroundObject": "缩略图里也能看见的关键物件",
  "camera": "镜头距离和构图",
  "continuityLink": "与上一格或下一格的连接",
  "imageMustShow": ["必须出现的元素"],
  "imageMustNotShow": ["禁止出现的重复元素或误导元素"],
  "prompt": "完整导演分镜，用于审稿和人工判断",
  "dreaminaPrompt": "短版英文生图提示词，用于真正提交给即梦"
}
```

`prompt` 可以保留原文、白话、分镜解释和上下文关系；`dreaminaPrompt` 必须短、直接、英文为主，不放中文原句，不把每个禁止物件都写进去，只保留一个核心视觉锚点、当前动作、镜头和固定风格锁。

## 质检规则

生图前先检查 JSON：

- 原句关联度：低于 8/10，不生成。
- 故事推进：如果删掉这一格不影响整章故事，不生成。
- 画面差异：相邻两格主体、场景、镜头、前景物重复，不生成。
- 动作可见：没有人物动作、物体变化或明确空间关系，不生成。
- 抽象词过多：出现“智慧、玄妙、道理、哲学、内涵”但没有具体画面，不生成。
- 风格漂移：没有固定角色、统一材质和统一色彩约束，不生成。
- 文字污染：提示词必须禁止文字、汉字、书法、标签、标牌、水印、印章。

生图后再检查图片：

- 不看提示词，只看图，能不能猜到这一句的大意。
- 图片是否真的出现了 JSON 里的 visualAnchor。
- 相邻图片是否像同一本漫画，而不是不同风格的插画合集。
- 是否有文字、水印、符号、奇怪手指、空白边、裁切错误。
- 不合格图片进入重生列表，不直接进站点。

## 执行计划

1. 第一章样板
   重写第一章分镜 JSON 和白话解释，验证图文关系、连贯性、风格一致性。

2. 小批量验证
   用第一章重新生成 8 张图，做接触表，人工判断是否达到“像漫画书”的标准。

3. 模板固化
   把第一章的分镜结构、提示词结构、质检规则写进脚本，让后续章节按同一规则扩展。

4. 逐章改造
   每次处理 5-10 章：先 JSON，后验证，最后生图。不要一次性把 80 章都交给随机生成。

5. 全量复核
   全书生成后按章节接触表检查：重复画面、风格漂移、原文错字、解释模板味、图文不贴合。

6. 最终发布
   只把通过复核的图片和文案进入站点构建；保留失败列表，便于后续重生。

## 第一章样板方向

第一章采用“少年想把世界说清楚，老者带他一路观察”的连续故事：

- 第 1 格：少年用绳尺量路，发现真正的路会转弯、分叉、入雾。
- 第 2 格：作坊里的面具和镜子说明名字只是临时入口。
- 第 3 格：两人看见天地未分之前的第一圈光。
- 第 4 格：山谷里万物显形，名字开始帮助人分辨世界。
- 第 5 格：少年放下行囊，才看见露水里的嫩芽。
- 第 6 格：他提灯看河岸、桥和村门，明白需求能看见边界。
- 第 7 格：洞中一泉分成明暗两流，说明“无”和“有”同源。
- 第 8 格：月门层层打开，终点不是口号，而是更多微妙变化的入口。
